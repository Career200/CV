I like being there for the whole arc — spec, design, code — with a sharp eye for the visual details and a soft spot for the conventions a team builds up. I like a codebase modern — not cutting-edge, but translated from cuneiform to TypeScript, offering prayers and sacrifices myself when needed.

And I'm picky about tools. React when it's genuinely interactive, Astro when it's content, a throwaway script when nothing's at stake. Styling's the same: plain CSS goes further than people think, Tailwind for speed, CSS-in-JS for components worth reusing, Radix or shadcn so I'm not reinventing the bicycle.

Underneath it all, I like making the team faster — pipelines in GitHub Actions, regressions fenced off with Jest.
